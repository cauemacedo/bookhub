# Planejamento do BookHub

Este arquivo reúne as etapas pensadas para organizar o desenvolvimento do projeto.

## Etapas

1. **Organização inicial:** criar o repositório e a documentação básica.
2. **Definição das funcionalidades:** decidir quais informações dos livros serão cadastradas e como o usuário poderá consultá-las.
3. **Desenvolvimento:** implementar as funcionalidades definidas, uma de cada vez.
4. **Testes e ajustes:** conferir o funcionamento e corrigir problemas encontrados.

## Como vamos organizar as tarefas

Antes de começar uma etapa, registrar o que precisa ser feito. Depois de concluir uma alteração, atualizar a documentação e criar um commit com uma mensagem que explique o que mudou.

O planejamento poderá mudar conforme as próximas aulas e a evolução do projeto.
