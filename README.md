# BookHub

O BookHub é um projeto de estudo criado durante as atividades do Dev Hub. A ideia é desenvolver aos poucos uma aplicação voltada à organização de livros e, ao mesmo tempo, praticar o uso do Git e do GitHub.

## Objetivo

Organizar o desenvolvimento do projeto, registrar as mudanças e manter as próximas tarefas documentadas.

## Documentação

Os arquivos na pasta `docs` ajudam a acompanhar o trabalho:

- [Planejamento](docs/PLANEJAMENTO.md): etapas e tarefas previstas.
- [Andamento](docs/ANDAMENTO.md): situação atual e próximos passos.

## Como acompanhar

As alterações ficam registradas no histórico de commits do GitHub. A documentação será atualizada conforme o projeto avançar.
