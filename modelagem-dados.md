# Modelagem de Banco de Dados

## Objetivo
Organizar uma estrutura básica de banco de dados para fins de aprendizado.

## Tabela: usuarios
- id (chave primária)
- nome
- email

## Tabela: projetos
- id (chave primária)
- nome
- usuario_id (chave estrangeira)

## Relacionamento
Um usuário pode ter vários projetos.
Cada projeto pertence a um usuário.
